Основное назначение
Приложение рекурсивно обходит веб-сайт, начиная с заданной базовой страницы, и скачивает все файлы, на которые находит ссылки.


1. Начинает с заданного URL (BASE_URL)

2. Приложение скачивает файлы более 400 различных форматов, включая:

Документы: PDF, DOC, DOCX, TXT, EPUB, FB2

Архивы: ZIP, RAR, 7Z

Изображения: JPG, PNG, GIF, BMP, SVG

Видео и аудио: MP3, MP4, AVI, MKV

Программный код: Java, C++, Python, JavaScript

Базы данных: SQL, DB, MDB

И многое другое.



3. Сохраняет структуру сайта в локальной файловой системе в той же директории что и приложение.

⚠️⚠️ Важно: Использование может нарушать условия обслуживания многих веб-сайтов! ⚠️⚠️
Разработано в учебных целях, для тестирования на собственных сайтах.
